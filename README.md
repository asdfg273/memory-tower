# 线性联想记忆塔的能力边界

**一句话**：Titans 式的线性联想记忆（快速权重塔）在精确名称存取上是真的，但作为**检索层**和**推理通道**，它在三个真实场景上都被更简单的方案打败——失败机制只有一条：**有损压缩发生在消费端之前，而消费端从不返回梯度**。

在 94.8 万字符真实对话上做 224 题冻结验收：**256 维压缩键的最近邻 .1518，朴素字符二合 .3661**（McNemar $b=52,c=4$，**$p<10^{-6}$**）；而结构擦除定理的 24 格检验里，键侧结构的放大率 **12/12 组为负**（$\text{amp}\le B(Z)-B(K)$）。

---

## 四组独立否定，同一个机制，每组都有正控

这四组不是四个零结果，而是同一个诊断的四种测量：

| 组 | 否定的是什么 | 结果 | 正控（证明"接得通、幅度够、机制活着"） |
| --- | --- | --- | --- |
| 注入 | 残差注入能增益推理 | M0=M1=M2=M3=**0.0000**，同题文本通道 .125/.250 | style prompt **1.000** |
| 深度 | 堆深能增表达力 | $L$ 层读出 = $q$ 的多项式滤波，增参 0、0/9 臂泛化 | 端到端 verbatim **1.000** |
| 压缩 | 键侧结构能被读出利用 | 白化把键 KNN 从 .0089 拉到 .1518，仍低于二合 .3661 | 白化本身 **17×** |
| 端到端 | 塔的联想读出有正贡献 | 键 KNN **.1518** vs 读出 $W$ **.0179**（相差 **8.5×**） | 键 KNN 本身就是正控 |

![H9：记忆注入画不出脸，一句文本可以](figures/h9_memory_vs_text.png)

> **图（H9 信道实验，§5.16）**：六行记忆臂（$W$=8/32/128 × 冻结/LoRA）画出的都是没有脸的人——雨伞黑影、窗前背影、只露一双鞋；最后一行只用**一句身份文本**，四张都是同一个人。CLIP-I 那些 .44–.47 里量到的几乎全是场景，不是身份。

## 如果你正在做 memory layer，这一节是给你的

照着抄结论，可以省掉下面四条弯路——每一条我们都用可机检的任务跑到头了：

**① 别做"把记忆向量注入残差流/注意力"来换推理能力。** 同底座同题：不注入、注入塔读出、注入 oracle 值向量、注入随机向量，四者全 **0.0000**；而同一批题上文本通道 0.125/0.250、style prompt 1.000。通道是通的、幅度是够的——失败在**方向**：注入是无条件输出指令，不是"按问题检索的记忆"。

**② 别靠"把塔堆深"换表达力。** $L$ 层线性读出严格等于 $q\sum_l W^l$，只增了计算、不增参数、不增容量；9 个臂零泛化收益。要容量只能加宽 $m$（且容量墙由 $N/m$ 决定，下面第 ④ 条）。

**③ 别靠"更宽的键"解决检索。** 免费的白化能拿 **17×**（.0089→.1518），但白化之后它**排第四**，落后三个零依赖的词面方法（二合 .3661 / 句级 idf .2143 / 消息级 idf .1920）。键侧几何只能修到"能用"，修不到"够用"。

**④ 别指望"训一个连接器/投影头"把记忆用起来。** 三条独立的任务拟合路径都没有救回读出：端到端训练投影在轻度改写上封顶 **.448**、重度改写 **.062**；InfoNCE 训 $W$ 留一 **.0000**；LoRA 在回路只买到 **+0.023**（噪声内）。

**该抄走的两条（都是免费的）：**
- **粒度与打分器必须配对**，没有单向最优：idf 换成句子级 **+.184**，朴素二合换成句子级 **−.079**；最优组合是"整条消息 + 二合"。
- **语义不变性在编码器里就丢了**：2048→$d$ 的线性投影变不出"两句是一个意思"，改写召回要靠编码器微调/增强，或者干脆退回词面。

**一句话验收标准**：如果你的记忆层在消费端之前做有损压缩、而消费端不为此返回梯度，那它最多能当"检索"，不能当"推理"；想越过后半句，只有两条路——**让读出进梯度**，或**换掉有损瓶颈**。
